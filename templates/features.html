Features

What Commons Data Weaver does today, grouped by the four threads plus the tools around them.

Loading files

  • Category: type a category name and press Load category. Files directly in the category are loaded (not subcategories).
  • CSV or list: paste or upload file names, one per line, or a CSV with a filename, file, title or name column. File: prefixes, underscores and full Commons URLs are accepted.
  • My list: files named on User:YourName/DataWeaver (a gallery or a plain list; lines inside HTML comments are skipped) load automatically when you open the tool, and again with the My list button.
  • Link to a category: {{ base_url }}/?category=Fishes_of_Kerala opens the tool and loads that category.
  • Everything is read first (file details, categories, captions in all languages, depicts), then the grid appears, with a progress bar.

Reviewing in the grid

  • Five images per row. Click an image to select it; selected images turn blue and the selected count turns red. Shift-click selects a range.
  • Each card shows badges for depicts (with the names of the first two), location, unsaved changes, saved and error.
  • Sort by filename, author, licence, observation date, upload date, camera, resolution, file size or starred, ascending or descending.
  • Filter with live counts: missing or has depicts, missing or has location, missing or has category (ignoring or counting hidden categories), and unsaved depicts changes. A free-text filter searches names, authors, licences, cameras and captions.
  • Stars mark photos for this session only. They can be sorted, grouped first or shown alone, and they are included in downloads.
  • Keyboard: A select all, G group, U ungroup, Esc clear selection, ← → move between files, ? help.

Depicts

  • Batch add or remove depicts (P180) for the selected files, found by searching Wikidata. Each result shows the item's image (P18) when it has one.
  • Subject suggestions include the Wikidata items (QID and label) that the file's or the selected files' Commons categories are linked to.
  • In the one-by-one view the depicts are highlighted at the top, with the caption and description beneath. A file without depicts is flagged so you can identify the subject.
  • The Depicts overview shows a word cloud and a frequency table of everything tagged so far; click a word to filter the grid to it, or download the table as CSV.

Categories

  • Category search combines several Commons searches, so partial names are found. If nothing matches you can press Enter to use the name as typed; a warning appears if that category does not exist yet.
  • After you pick a subject, the item's Commons category (P373), taxon name (P225) and label are checked against Commons and offered as one-click suggestions, or Add all.
  • Add or remove categories in bulk. Categories added by templates are shown but cannot be removed from the file page by this tool.

Location

  • Type coordinates, click a map to drop a pin, or search for a place on Wikidata. Search on OpenStreetMap is available if you switch it on in the settings.
  • Apply one location to all selected files, or set it per file. The map can be hidden.
  • Saved as a {{ '{{Location}}' }} template on the file page; an existing location template is updated in place.

Series and Other versions

  • Series menu: grouped (manual), ungrouped (all files), automatic by time (same camera, shots within a set number of seconds) or automatic by file name. One menu switches between the grouped and ungrouped views.
  • A series shows one thumbnail and a photo count. Opening it shows a collage, where you add depicts and categories to the whole series or to the photos you select.
  • If photos in a series were uploaded by different users, a warning is shown on the card and in the collage, and manual grouping asks for confirmation.
  • Other versions: add the other photos of a series to a file's Information template, after Permission, as a <gallery> with captions. A file cannot list itself. Link all as Other versions does this for every photo in the series at once.

More on each file

  • Captions in every language can be edited; descriptions are shown read-only.
  • Image notes: draw rectangles on the image and write notes in the format the ImageAnnotator gadget shows on the file page (needs an autoconfirmed account).
  • Personality rights: a button on each file adds {{ '{{Personality rights}}' }} above the licence header, with a green or red ring showing whether it is already there.
  • Batch panel: collapsible; select all, none, invert, starred; star, group, ungroup; batch depicts, categories and location; save selected or save all.

Saving and exporting

  • Nothing is written until you save. Unsaved values are shown in red. Save one file, the selected files or everything; a summary dialog shows what will be written first.
  • Edit summaries read Metadata updated with Commons Data Weaver via #DataWeaver, plus the hashtag of the Project you choose (Bioregister, Folkland, Heritage or Wikivoyage).
  • The edit log at the bottom of the batch panel lists every edit of the session, with diff links and any errors.
  • Download all, filtered, selected or starred files as JSON or CSV, including captions, descriptions, categories, depicts, location, series, other versions, annotations and the starred flag.

Web app only

  • Wikimedia login with OAuth 2.0: edits are made as you, and your password is never seen by this tool. You can start preparing edits before logging in; the login opens in a new tab so nothing is lost.
  • Settings (gear): choose the interface language and set up typing tools (input methods for writing in other scripts, from jQuery IME). See Technology for how translations work.
  • Privacy by default: third-party place search is off until you switch it on. See the privacy note.
