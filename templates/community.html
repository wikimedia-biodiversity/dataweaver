Community

Data Weaver is a community tool. It is built in the open, and every kind of help is welcome.

Get help and report problems

  • Open an issue in the issue tracker. Say what you did, what you expected and what happened, and include the browser and the file or category involved.
  • For questions about how to use the tool, start with How to use.
  • The maintainer can also be reached through {{ author }}'s Meta user page.

Contribute

  • Translate. Interface languages are JSON files in static/i18n/. Copy en.json, translate the values, add a line to languages.json and send a pull request. The qqq.json file explains each message. Translations of the tool's own labels go under the @app key, one English phrase at a time, so partial translations are welcome.
  • Add input methods or fix typing. Typing tools come from jQuery IME; input methods for your language belong there and benefit all of Wikimedia.
  • Improve the code. See CONTRIBUTING.md in the repository for setup, tests and how the interface is generated from the user script.
  • Try it on your own projects and tell us which workflow was hard. Real examples from Heritage, Wiki Village, Folkland and biodiversity work shape what gets built next.

Working together

Everyone taking part is expected to follow the Universal Code of Conduct. Edits made with the tool are your own edits: please follow Commons' guidelines on licensing, personality rights and bulk changes, and review changes before saving.

Projects the tool is made for

  • Bioregister: biodiversity photographs and observations.
  • Heritage: monuments, sites and cultural heritage.
  • Wiki Village: images for the Wiki Village project.
  • Folkland: folk culture, crafts, festivals and traditions.

Choosing a project adds its hashtag to your edit summaries so the community can find and review the work.
