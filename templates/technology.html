Technology

A small Flask service that handles the Wikimedia login and edits, plus a browser interface written in plain JavaScript. Hosted on Wikimedia Toolforge.

How a save works

  1. Reading is direct. Your browser asks Commons and Wikidata for file lists, details, depicts and search results. These are public and need no login.
  2. Writing goes through Data Weaver. When you save, the browser sends the change to /api/write. The server checks the request, adds the edit token and your OAuth access token, and forwards it to Commons.
  3. The proxy is deliberately narrow. It accepts only edit (by page id), wbeditentity and wbsetlabel on file entities, drops every other parameter, rejects cross-origin requests, applies maxlag, limits edits per minute and makes sure the summary carries #DataWeaver.
  4. Sessions expire cleanly. Access tokens are refreshed automatically; if Wikimedia revokes access, the tool asks you to log in again and keeps your work.

Localisation and typing tools

The gear in the navigation bar opens the settings. The interface language is stored in your browser. Menus and dialogs come from static/i18n/<code>.json; the tool's own interface is translated by exact English text under the @app key, so a translator can add labels one at a time without touching any code. Anything not yet translated stays in English.

Typing tools load jQuery IME on demand. After you choose a language and input method, every text field in the tool accepts it, including the subject and category search boxes. Press Ctrl+M to switch it off and on while typing.

Security and privacy choices

  • Strict Content-Security-Policy: scripts run only from this site, with no inline scripts and no third-party scripts, styles or fonts.
  • Session cookie is HttpOnly, Secure and SameSite=Lax; writes also need a custom header and a matching origin.
  • OpenStreetMap place search is off by default because it sends typed text to a service outside Wikimedia.

The source, deployment guide and tests are in the repository.
