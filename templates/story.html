Story and workflows

From a pile of untagged photographs to files that Wikimedia Commons, Wikidata and search engines can understand.

Why it exists

A single field trip can add hundreds of photographs to Commons. Each one needs a species or subject, the right categories, a place and, ideally, a link to the other shots of the same animal or plant. Doing that file by file, across a file page, a structured-data tab and a category editor, is slow enough that much of it never happens.

Data Weaver was started inside the Wikimedia Biodiversity Taskforce, which works on photographs from Keralam and the Western Ghats. Two things shaped it: the way iNaturalist puts the species, place and map next to each observation, and the click-to-select speed of Cat-a-lot. The idea was to bring both to Commons: see the whole set, select what belongs together, and describe it once.

It began as a Commons user script. This web version, hosted on Toolforge with a Wikimedia login, gives the same interface to anyone with an account and no installation, and adds settings for interface language and typing in other scripts.

Principles

  • Nothing is saved until you say so. Changes are staged and shown in red, and a summary dialog appears before saving.
  • Edits are yours. They are made under your account, with an edit summary that names the tool and the project.
  • Structured data first. Depicts (P180) is treated as the main fact about a file; categories and location support it.
  • Useful beyond biodiversity. The same steps work wherever Commons files lack structured data.

Workflow 1: tag a field trip

  1. Load the trip's category, then sort by observation date.
  2. Set Series to Auto by time so bursts of the same animal collapse into one card.
  3. Open a series, search the species, and pick the Wikidata item. Accept the suggested Commons category.
  4. Use Link all as Other versions so each photo points to its siblings.
  5. Select everything from one site, pin the location once, and apply it.
  6. Choose the project Bioregister, save, and check the edit log.

Workflow 2: find and fix what is missing

  1. Load a large category, or list the files on User:YourName/DataWeaver and open the tool.
  2. Set the filter to Missing depicts (or Missing location, Missing category); the menu shows how many files each filter will leave.
  3. Press A to select all shown, add the subject or location they share, and repeat with a narrower filter or a different sort.
  4. Open the Depicts overview to see what is already well covered and what is not.

Workflow 3: heritage, travel and folk culture

For a monument, a festival or a craft, the subject is usually a Wikidata item for the building, event or practice rather than a species. Search it in the same box, add the depicts, the matching category and the location, and group the photographs of the same site. Choose Heritage, Wiki Village or Folkland so the edit summary shows which project the work belongs to.

Workflow 4: annotate and protect

In the one-by-one view, draw image notes on parts of a photograph, for example to label the species in a group shot. The Personality rights button adds the template to files that show recognisable people.
