How to use Commons Data Weaver

From opening a category to saving structured data, in ten steps. Open the tool in another tab and follow along.

  1. Log in

    Press Log in at the top right and allow Data Weaver to edit on your behalf. You can load files and prepare edits first; you only need to be logged in to save. The login opens in a new tab, so nothing in the tool tab is lost.

  2. Choose a project

    In the top bar, set Project to Bioregister, Folkland, Heritage or Wiki Village. Your edit summaries then end with #DataWeaver #Project. Leave it empty to use only #DataWeaver. The choice is remembered in your browser. Choosing a project also adds a Help needed flag to each file, for marking problematic files with that project's category (see step 6).

  3. Load files

    Type a category name and press Load category; or press CSV / list… and paste file names; or create the page User:YourName/DataWeaver with one File: name per line and press My list (it loads by itself when the tool opens). Wait for the progress bar to finish: captions and depicts are read after the thumbnails appear.

  4. Find what needs work

    Use Filter to show files with missing depicts, location or category; the menu shows how many files each option leaves. Use Sort to order by name, author, licence, dates, camera, resolution or size. Mark favourites with ★ (they stay for the session) and use the Stars menu to show only starred, or only files you have not starred yet.

  5. Select and tag in bulk

    Click images to select them (blue border). Shift+click selects a range. The Select buttons (or A, I, Esc) select all shown files, invert the selection, or clear it. Press the yellow Batch edit button (B) to open the panel; it changes all selected files, so check the Selected count first. In the panel, search a Wikidata item under Depicts, a Commons category under Categories, or enter or pin a Location, then press Add to selected or Apply to selected. Press the button again to hide the panel.

  6. Work one file at a time

    Press ⤢ on a card. At the top you see what the file depicts; if nothing, search the subject and pick the right Wikidata item. Suggested Commons categories appear below; add them with one click. Set the location on the map, edit captions (your interface language first, then English), draw image notes, then Save & next, or ▶ to move on without saving. Everything fits on one screen; boxes scroll inside. Pick the image Size and Fit above the picture; New tab opens it on its own. Keys: ← → move, Space star, P Personality rights, H help needed.

  7. Use series for similar photos

    Set Series to Auto by time or Auto by file name to get suggestions, or select photos and press Group (G). A series is one card with a count; press ⤢ to open a collage and tag the whole series. If the uploaders differ you will see a warning. Link all as Other versions lists the photos in each other's Information template.

  8. Check the overview and statistics

    Depicts overview shows a word cloud and a frequency table of what is tagged. Click a word to filter the grid. Statistics shows contributors, sizes, upload activity, cameras and a map of the loaded files, with downloads for every chart. Use the small menu on each chart to switch between bars, pie, donut, line and more. To share it, use /?stats&category=Category_name.

  9. Save

    Unsaved values are red. Press Save selected or Save all changes, read the summary dialog and confirm. The Edit log at the bottom of the left panel lists every edit with a diff link. Errors are shown on the card and in the log.

  10. Download and set up your preferences

    The Download menu exports all, filtered, selected or starred files as JSON or CSV, named dataweaver-category-date-time. The gear in the top bar sets the interface language and typing tools: switch on input methods, choose a language and layout, and test it in the box. Your system keyboard stays the default. Press Ctrl+M in any text field to switch to the typing tool, and again to switch back (it starts on the system keyboard every visit).

Keyboard shortcuts

ASelect all files in the open window (the grid, or an open series)
IInvert the selection among the shown files
SpaceStar or unstar the selected files; in the one-by-one view, the open file
BShow or hide the batch edit panel
G / UGroup / ungroup the selected files
P / HOne-by-one view: add Personality rights / flag as needing help (project with a help category)
EscClear the selection; press again to close an open series or file
← →Previous / next file in the one-by-one view
Ctrl+MIn a text field: switch between the system keyboard and your typing tool (works while typing)
?Show the shortcut list

Shortcuts are ignored while you are typing in a field.

Tips and troubleshooting

  • "Log in to save" appears. Log in in the new tab, then press Save again. Your edits are still there.
  • Your login expired. The tool tells you and keeps your work; log in again and save.
  • A file shows an error. Hover the red badge or open the Edit log. An edit conflict means someone changed the page meanwhile: save that file again.
  • No place results from OpenStreetMap. It is off by default; switch it on in the gear settings. Wikidata places always work.
  • A pop-up was blocked. Allow pop-ups for this site, or the login will open in this tab instead.
  • Image notes are disabled. They need an autoconfirmed account.
  • Large categories load in batches; use the filter or a CSV subset for big jobs, and review changes before saving.
