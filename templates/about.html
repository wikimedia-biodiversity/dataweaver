About

Commons Data Weaver helps you improve the structured data of Wikimedia Commons files: what a file depicts, which categories it belongs to, where it was taken, and which other files show the same subject.

What it is

Many Commons files sit in a category with a good title but little structured data. Data Weaver loads a category, a list of file names or your own list page, shows the files in a grid, and lets you add what is missing, in bulk or one file at a time, then saves the changes to Commons under your own account.

It was built for biodiversity work, where one field trip produces hundreds of photographs of a few species. Nothing in it is specific to biology: the same steps work for monuments, places, objects and events.

Four threads

  • Depicts (P180): link the file to the Wikidata item for its subject.
  • Categories: add or remove Commons categories, with suggestions taken from the Wikidata item's own Commons category.
  • Location: pin coordinates on a map, or search a Wikidata place, and apply them to many files.
  • Other versions: group photos of the same subject and list them in each file's Information template, so readers can find the rest of the series.
